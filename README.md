# 🌐 Personal Developer Portfolio & Freelance Website

A modern, high-performance, and responsive single-page developer portfolio built to showcase academic background, enterprise work experience, projects, and technical skill sets.

**🔗 Live Website:** [kdpersonalwebsite.netlify.app](https://kdpersonalwebsite.netlify.app)

---

## ✨ Features

- **Responsive & Modern UI:** Minimalist dark-mode design engineered with **Tailwind CSS** and typography powered by the **Inter** font family.
- **Dynamic Internationalization (i18n):** Client-side multilingual translation engine supporting:
  - 🇬🇧 **English (EN)**
  - 🇩🇪 **German (DE)**
  - 🇸🇦 **Arabic (AR)** (with full dynamic RTL layout switching)
- **Zero-Dependency Architecture:** Self-contained, lightweight single-page static site with zero heavy build steps.
- **Automated CI/CD:** Continuous deployment pipeline managed via **Netlify** synced with GitHub.

---

## 🛠️ Tech Stack

- **Markup & Styling:** HTML5, [Tailwind CSS](https://tailwindcss.com/) (CDN)
- **Scripting:** Vanilla JavaScript (ES6+) for DOM manipulation, dynamic translation, and local storage persistence
- **Version Control & CI/CD:** Git, GitHub, [Netlify](https://www.netlify.com/)
